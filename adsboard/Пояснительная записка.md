ВВЕДЕНИЕ
В современном мире интернет-сервисы для размещения объявлений являются одним из наиболее востребованных видов веб-приложений. Доски объявлений позволяют пользователям быстро и удобно публиковать предложения о продаже товаров, предоставлении услуг или поиске чего-либо, охватывая широкую аудиторию без значительных затрат.
Целью данного курсового проекта является разработка веб-сайта доски объявлений с применением собственного PHP-фреймворка, построенного на архитектурном паттерне MVC (Model-View-Controller). Проект реализован в рамках третьего блока курса серверной веб-разработки.
В ходе работы были применены технологии и подходы, изученные в лабораторных работах: архитектура MVC, паттерны Active Record и Singleton, работа с базой данных через PDO, система маршрутизации запросов, хранение данных в формате JSON с последующим импортом в базу данных.
Цель проекта: разработать веб-сайт доски объявлений с возможностью просмотра, добавления, редактирования и удаления объявлений с применением PHP-фреймворка на основе паттерна MVC.

Задачи проекта:

- проанализировать предметную область и аналоги
- спроектировать структуру базы данных
- реализовать систему маршрутизации запросов
- разработать модели данных с применением паттерна Active Record
- реализовать главную страницу со списком объявлений и фильтрацией по категориям
- реализовать страницу просмотра отдельного объявления
- разработать функционал добавления, редактирования и удаления объявлений
- реализовать импорт тестовых данных из JSON-файла в ба-зу данных
  Глава 1. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ
  1.1. Анализ предметной области
  Доска объявлений представляет собой веб-сервис, позволяющий пользователям публиковать и просматривать объявления различной тематики. Основное назначение подобных сервисов состоит в упрощении коммуникации между продавцами и покупателями, работодателями и соискателями, а также в иных случаях, когда требуется донести информацию до широкой аудитории.
  Среди наиболее известных аналогов можно выделить Avito и Юла. Avito является крупнейшей российской платформой объявлений с расширенными возможностями: поиском, фильтрацией, встроенным чатом и системой верификации пользователей. Юла ориентирована на мобильных пользователей и предлагает геолокационный поиск объявлений поблизости.
  Разрабатываемый проект представляет собой упрощенную реализацию доски объявлений без авторизации, ориентированную на демонстрацию принципов серверной веб-разработки с применением архитектурного паттерна MVC.
  1.2. Архитектура приложения
  В основе проекта лежит паттерн MVC (Model-View-Controller), разделяющий приложение на три логических слоя.
  Model (Модель) отвечает за работу с данными и взаимодействие с базой данных. В проекте реализован базовый абстрактный класс ActiveRecordEntity, от которого наследуются все модели. Он содержит универсальные методы для выборки, сохранения и удаления записей.
  View (Представление) формирует HTML-страницы на основе шаблонов и переданных данных. Класс View принимает имя шаблона и массив переменных, извлекает их через функцию extract() и подключает нужный файл шаблона.
  Controller (Контроллер) является связующим звеном между запросом пользователя, моделями и представлениями. Контроллер получает данные от моделей и передает их в шаблоны для формирования ответа.
  1.3. Паттерны проектирования
  В проекте применены следующие паттерны проектирования.
  Active Record. Каждая модель (класс Ad) самостоятельно управляет своим жизненным циклом в базе данных. Статические методы findAll() и getById() выполняют выборку данных. Метод save() автоматически определяет, нужно ли выполнить INSERT или UPDATE, исходя из наличия идентификатора у объекта. Метод delete() удаляет запись из базы данных.
  Singleton. Класс Db реализован по паттерну Singleton, гарантируя, что соединение с базой данных устанавливается единственный раз за время выполнения запроса. Это позволяет избежать избыточных подключений к базе данных.
  Front Controller. Файл index.php является единственной точкой входа в приложение. Все запросы перенаправляются на него через .htaccess, после чего производится маршрутизация.
  1.4. Анализ функциональности проекта
  Проект реализует следующий набор функций.
  Просмотр списка объявлений. На главной странице отображаются все объявления из базы данных с заголовком, категорией, датой публикации, кратким описанием и ценой.
  Фильтрация по категориям. Пользователь может отфильтровать объявления по одной из пяти категорий: Электроника, Одежда, Транспорт, Недвижимость, Разное. Активная категория визуально выделяется.
  Просмотр отдельного объявления. На странице объявления отображается полная информация: заголовок, категория, дата, цена и полный текст.
  Добавление объявления. Форма с полями для ввода заголовка, текста, цены и выбора категории. Реализована валидация на стороне сервера.
  Редактирование объявления. Форма, аналогичная форме добавления, с предзаполненными текущими данными.
  Удаление объявления. Страница подтверждения с кнопками удаления и отмены.
  Импорт данных из JSON. Скрипт import.php читает тестовые объявления из файла ads.json и записывает их в базу данных.

2.2. Структура проекта
Проект организован в соответствии со стандартом PSR-4, согласно которому каждый класс хранится в отдельном файле, а путь к файлу соответствует пространству имён класса. Структура каталогов приведена ниже.

- www/ -- точка входа, файл index.php и .htaccess
- src/MyProject/Controllers/ -- контроллеры приложения
- src/MyProject/Models/ -- модели данных
- src/MyProject/Services/ -- сервисные классы (Db)
- src/MyProject/View/ -- класс рендеринга шаблонов
- templates/ -- HTML-шаблоны страниц
- data/ -- JSON-файл с тестовыми данными и скрипт импорта
  2.3. Маршрутизация
  Все входящие запросы перенаправляются Apache-сервером через .htaccess на файл index.php. Параметр route содержит запрошенный URI.
  Файл index.php регистрирует автозагрузчик классов через spl_autoload_register(), затем загружает таблицу маршрутов из routes.php и подбирает подходящий маршрут с помощью регулярных выражений. После нахождения совпадения создается объект соответствующего контроллера и вызывается нужный метод.
  Таблица маршрутов проекта содержит следующие записи.
- /ads/add -- добавление нового объявления
- /ads/{id}/edit -- редактирование объявления
- /ads/{id}/delete -- удаление объявления
- /ads/{id} -- просмотр объявления
- / -- главная страница со списком
  2.4. Модель данных и паттерн Active Record
  Базовый абстрактный класс ActiveRecordEntity содержит всю логику работы с базой данных. Дочерние классы наследуют методы findAll(), getById(), save() и delete(), а также обязаны реализовать абстрактный метод getTableName(), возвращающий имя таблицы.
  Магический метод \_\_set() перехватывает попытку задать несуществующее свойство (например, created_at) и преобразует имя из формата snake_case в camelCase (createdAt), после чего присваивает значение нужному свойству.
  Метод save() использует PHP Reflection API для получения списка свойств объекта и автоматического построения SQL-запроса. Если у объекта есть идентификатор, выполняется UPDATE, иначе INSERT. После вставки новой записи идентификатор подтягивается через метод lastInsertId().
  Класс Ad наследует ActiveRecordEntity и содержит свойства title, text, price, category, createdAt, а также геттеры и сеттеры для каждого из них. Статическое свойство $categories хранит список допустимых категорий и используется для валидации и вывода в шаблонах. Метод findByCategory() позволяет получить объявления конкретной категории.
  2.5. Импорт данных из JSON
  Тестовые данные хранятся в файле data/ads.json в виде массива объектов с полями title, text, price и category. Скрипт data/import.php читает этот файл с помощью функции file_get_contents(), декодирует JSON через json_decode() и вставляет каждую запись в базу данных через подготовленный PDO-запрос.
  Такой подход позволяет разделить данные и логику приложения, а также упрощает первоначальное наполнение базы данных при развертывании проекта.
  2.6. Шаблоны и представления
  Класс View принимает имя шаблона и массив переменных. Переменные извлекаются функцией extract(), после чего подключается нужный PHP-файл шаблона. Для предотвращения конфликтов между заголовками HTTP и выводом контента используется буферизация вывода через ob_start() и ob_get_contents().
  Все шаблоны построены по единой схеме: в начале подключается header.php с HTML-шапкой и стилями, затем идет контент страницы, в конце подключается footer.php. Стили вынесены непосредственно в header.php и обеспечивают минималистичный внешний вид.
  Для предотвращения XSS-атак все данные, выводимые из базы данных, экранируются функцией htmlspecialchars(). При выводе многострочного текста применяется nl2br() для сохранения переносов строк.
  ЗАКЛЮЧЕНИЕ
  В ходе выполнения курсового проекта был разработан веб-сайт доски объявлений с применением собственного PHP-фреймворка, построенного на архитектурном паттерне MVC.
  В процессе работы были реализованы следующие элементы.
- система маршрутизации запросов на основе регулярных выражений
- автозагрузка классов в соответствии со стандартом PSR-4
- паттерн Active Record для работы с базой данных
- паттерн Singleton для класса соединения с базой данных
- PHP Reflection API для автоматического построения SQL-запросов
- импорт тестовых данных из JSON-файла
- валидация форм на стороне сервера
- фильтрация объявлений по категориям
- полный цикл CRUD для объявлений
  Все поставленные задачи решены, цель проекта достигнута. В качестве перспектив развития можно выделить добавление системы авторизации пользователей, поиска по объявлениям, пагинации списка, а также загрузки изображений к объявлениям.
